### TP3 - Chatbots con TF-IDF y Embeddings

Descripción

Desarrollo y comparación de dos chatbots de atención al cliente para Giulya, un comercio de accesorios de moda y artículos de viaje.

Se utilizó un diccionario de 25 preguntas y respuestas, implementando dos técnicas de Procesamiento del Lenguaje Natural:

TF-IDF: representación de textos basada en la importancia de las palabras.

Embeddings: representación semántica mediante el modelo preentrenado es_core_news_md de spaCy.

Ambos chatbots utilizan la similitud del coseno para seleccionar la respuesta más cercana a la consulta del usuario.

Tecnologías utilizadas

Python

Google Colab

scikit-learn

spaCy

TF-IDF obtuvo mejores resultados para este conjunto de preguntas, demostrando que un modelo más complejo no necesariamente tiene un mejor rendimiento.
